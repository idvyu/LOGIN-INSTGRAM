### CCNP Enterprise 350-401 --&#x20;

#### وش يغطي المنهج ؟

* Enterprise Network Design & Architecture
* High Availability: HSRP / VRRP / GLBP
* Software-Defined Access & SDN
* Virtualization
* Infrastructure
* Troubleshooting
* Security
* Wireless Security
* Network Automation & APIs

#### توزيع المنهج

* Architecture: 15%
* Infrastructure: 30%
* Virtualization: 10%
* Troubleshooting: 20%
* Security: 10%
* Automation: 15%

#### مين يناسبه؟

* Network Engineers
* System Engineers
* Network Administrators
* Infrastructure Engineers
* Network Support Engineers
* اللي عنده أساسيات شبكات ويبغى مستوى متقدم

#### احفظها:

> **CCNP Enterprise = Design + Infrastructure + HA + Security + Troubleshooting + Automation + SDN**
