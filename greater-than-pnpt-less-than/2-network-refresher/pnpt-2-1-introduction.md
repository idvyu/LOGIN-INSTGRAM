# PNPT - 2 - 1 = introduction

## Networking Refresher — مراجعة أساسيات الشبكات

### 1. مقدمة

الأمن السيبراني مجال واسع، ومستحيل تحفظ كل الأوامر والأدوات؛ لذلك لازم تدوّن ملاحظاتك وتراجعها باستمرار.

الشبكات من أهم الأساسيات في اختبار الاختراق، وإذا كنت فاهم TCP وUDP وOSI والـ Handshake، تقدر تتجاوز المراجعة إذا كنت متمكن منها.

### 2. عناوين IP

عنوان IP هو عنوان يُستخدم للتعرّف على الأجهزة والتواصل بينها عبر الشبكة.

فيه نوعين رئيسيين:

* **IPv4:** عنوان مكوّن من 32 بت، ويُكتب بالنظام العشري، مثل `192.168.1.10`.
* **IPv6:** عنوان مكوّن من 128 بت، ويُكتب بالنظام الست عشري، مثل `2001:db8::1`.

لمعرفة عناوين الشبكة في Linux، تقدر تستخدم:

```
ip addr
```

والأمر القديم هو:

```
ifconfig
```

وفي Windows:

```
ipconfig
```

التواصل باستخدام عناوين IP يكون على **الطبقة الثالثة (Network Layer)** من نموذج OSI.

### 3. كيف يتكوّن IPv4؟

عنوان IPv4 يتكوّن من 32 بت، مقسمة إلى أربعة أجزاء، كل جزء حجمه 8 بت ويسمى Octet.

مثال:

`192.168.1.10`

كل Octet يتكوّن من 8 بت، وكل بت تكون قيمته 0 أو 1.

قيم البتات من اليمين لليسار:

`128, 64, 32, 16, 8, 4, 2, 1`

إذا كانت جميع البتات مفعّلة، نجمع القيم ويطلع الناتج:

`128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255`

وإذا كانت آخر ثلاثة بتات مفعّلة:

`4 + 2 + 1 = 7`

عشان كذا كل Octet في IPv4 تكون قيمته من 0 إلى 255.

إجمالي حجم IPv4 هو 32 بت، أي 4 بايت.

### 4. ليه نحتاج IPv6؟

IPv4 يحتوي نظريًا على:

`2^32 = 4,294,967,296`

عنوانًا ممكنًا.

ومع زيادة عدد الأجهزة المتصلة بالإنترنت، ما عاد عدد عناوين IPv4 كافيًا لتلبية الاحتياج العالمي.

عشان كذا ظهر IPv6، اللي يحتوي على 128 بت، ويوفر عددًا هائلًا من العناوين:

`2^128`

والفرق الأساسي بينهم أن IPv4 يتكوّن من 32 بت، بينما IPv6 يتكوّن من 128 بت.

### 5. وش هو NAT؟

**NAT = Network Address Translation**

ترجمته: ترجمة عناوين الشبكة.

خلنا نفترض عندك في البيت 20 جهازًا، مثل الجوالات والكمبيوترات والكاميرات والتلفزيونات الذكية.

الأجهزة هذي غالبًا تستخدم عناوين IP خاصة داخل شبكتك، والراوتر يستخدم NAT عشان يسمح لها بمشاركة عنوان IPv4 عام عند الاتصال بالإنترنت.

مثال على عنوان خاص:

`192.168.1.10`

وعنوان الإنترنت العام يكون مختلفًا، ويظهر للمواقع والخدمات الخارجية بحسب إعدادات الشبكة.

بكذا، مو لازم كل جهاز في البيت يحتاج عنوان IPv4 عامًا مستقلًا.

### 6. عناوين IP الخاصة

فيه ثلاث نطاقات رئيسية لعناوين IPv4 الخاصة:

| النطاق          | مدى العناوين                    |
| --------------- | ------------------------------- |
| Private Class A | `10.0.0.0 – 10.255.255.255`     |
| Private Class B | `172.16.0.0 – 172.31.255.255`   |
| Private Class C | `192.168.0.0 – 192.168.255.255` |

أمثلة:

* `192.168.1.10` عنوان خاص شائع في شبكات المنازل.
* `10.1.1.1` عنوان خاص ممكن يُستخدم في شبكات المؤسسات.
* `172.16.1.5` عنوان خاص أيضًا.

أي عنوان يبدأ بـ `192.168` يقع ضمن نطاق العناوين الخاصة.

**ملاحظة:** تصنيفات Class A وB وC هي التصنيفات التقليدية؛ أما الشبكات الحديثة فتستخدم غالبًا CIDR وتقسيم الشبكات باستخدام Subnet Masks.

### 7. كيف تتواصل الأجهزة مع الإنترنت؟

خلنا نربط المعلومات ببعض:

1. جهازك يحصل على عنوان IP خاص، مثل `192.168.1.10`.
2. يرسل البيانات إلى الراوتر.
3. الراوتر يستخدم NAT لترجمة عنوان المصدر عند الحاجة.
4. يخرج الاتصال إلى الإنترنت باستخدام عنوان IP العام.
5. ترجع الاستجابة إلى الراوتر، ثم يوجّهها إلى الجهاز الصحيح.

بهذه الطريقة، تقدر عدة أجهزة تستخدم IPv4 وتتصل بالإنترنت من خلال عنوان عام واحد في كثير من الشبكات المنزلية.

### الخلاصة

احفظ هذي النقاط لأنها أساس الشبكات:

* IPv4 = 32 بت.
* IPv6 = 128 بت.
* كل Octet في IPv4 = 8 بت، وقيمته من 0 إلى 255.
* الطبقة الثالثة في OSI مسؤولة عن التوجيه باستخدام عناوين IP.
* NAT يسمح بمشاركة عنوان عام بين عدة أجهزة في كثير من الشبكات.
* نطاقات IP الخاصة هي `10.0.0.0/8` و`172.16.0.0/12` و`192.168.0.0/16`.
* فهم IP وSubnetting مهم جدًا للشبكات واختبار الاختراق.
